# WatchTogether

P2P видеозвонки с демонстрацией экрана — минималистичный аналог Discord для 2 человек.

## Возможности

- Видео/аудио звонки (P2P, без сервера для медиа)
- Демонстрация экрана со звуком
- Микрофон работает независимо от камеры
- Комнаты по ID
- Работает в Chrome, Edge, Firefox

## Архитектура

```
Браузер 1 ←── WebRTC (P2P) ──→ Браузер 2
      ↑                           ↑
      └──── WebSocket сигналинг ──┘
```

Сигналинг-сервер только соединяет участников. Видео/аудио идёт напрямую между браузерами.

## Локальный запуск

```bash
npm install
npm start
# Открыть http://localhost:3000
```

## Деплой на Fly.io

### 1. Установить flyctl

**Windows (PowerShell):**
```powershell
iwr https://fly.io/install.ps1 -useb | iex
```

**Mac/Linux:**
```bash
curl -L https://fly.io/install.sh | sh
```

### 2. Войти в аккаунт

```bash
fly auth login
```

### 3. Запустить приложение

```bash
# Первый деплой
fly launch --name watchtogether

# Или если уже настроено:
fly deploy
```

### 4. Открыть

```bash
fly open
```

Получишь URL типа `https://watchtogether.fly.dev` — отправляй другу, звоните.

## Использование

1. Открой ссылку в браузере
2. При входе разреши микрофон
3. Нажми **Камера** чтобы включить видео
4. Нажми **Экран** чтобы показать экран (в Chrome поставь галочку "Поделиться аудио", в Firefox выбери "Вкладку")
5. **Мик** — включить/выключить микрофон

## Требования

- Node.js 18+
- Современный браузер с поддержкой WebRTC
- HTTPS (кроме localhost) — WebRTC требует безопасный контекст
